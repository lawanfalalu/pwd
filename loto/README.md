# Loto – A Voice-Assisted Watch for Visually Impaired Persons

Loto (Hausa for *Time*) is a mobile application that helps visually impaired users know the current time through voice announcements. The app functions as a talking watch and provides time information in both **Hausa** and **English**.

## Features

* 🕒 Speaks the current time aloud.
* 🌍 Supports Hausa and English languages.
* 📱 Simple and accessible user interface.
* 📳 Shake-to-hear-time functionality.
* 🔊 Clear voice output using Text-to-Speech (TTS).
* ♿ Designed for visually impaired and low-vision users.

## How It Works

Users can shake their phone or press a button to hear the current time announced in their selected language. The application converts the device's current time into natural language and speaks it using the phone's built-in Text-to-Speech engine.

### Example Output

**English:**

> "The time is 3:45 PM."

**Hausa:**

> "Karfe uku da mintuna arba'in da biyar na yamma."
